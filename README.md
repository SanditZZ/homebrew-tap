# homebrew-tap

Personal Homebrew tap for [SanditZZ](https://github.com/SanditZZ)'s apps.

## Install

```bash
brew tap sanditzz/tap
brew install --cask idle-tapper
```

or in one line:

```bash
brew install sanditzz/tap/idle-tapper
```

## Casks

| Cask | Source |
|---|---|
| `idle-tapper` | [SanditZZ/idle-tapper-macos](https://github.com/SanditZZ/idle-tapper-macos) |

`Casks/idle-tapper.rb` is updated automatically by that repo's release workflow whenever a new version ships — it is not meant to be hand-edited. See [RELEASING.md](https://github.com/SanditZZ/idle-tapper-macos/blob/main/RELEASING.md) there for how.
